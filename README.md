# Studio Ademwerk

Statische website (HTML/CSS/JS, geen build-stap).

- `index.html` — homepage
- `ademwerk.html`, `over.html`, `contact.html` — subpagina's
- `css/style.css` — alle stijlen (kleuren bovenin als variabelen)
- `js/main.js` — menu, header bij scrollen, reviews-slider

Lokaal bekijken: open `index.html` in de browser, of `npx serve .`

Nog te doen: echte foto's (zoek op `class="ph`), echte ervaringen, tarieven,
adres en social-links invullen (zoek op `[`).
